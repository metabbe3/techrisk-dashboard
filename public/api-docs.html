Authentication

All authenticated endpoints require a Bearer token. Tokens are generated by Tech Risk Dashboard admins via the admin panel. If you need API access, request a token from your admin.

Pass the token in the Authorization header:

Authorization: Bearer 1|abc123def456...

How to get a token: Contact your Tech Risk Dashboard admin. They will create a token with the appropriate endpoint access, expiration, and abilities for your integration. Tokens can be scoped to specific endpoints only (e.g., read-only incidents).

Important: Tokens expire based on their configured expires_at date. Tokens are also disabled after 90 days of inactivity unless auto-renewal is configured. If your token stops working, ask your admin to check or regenerate it.

Response Format

All API responses use a standardized envelope:

Success Response

{
  "code": 200,           // integer - HTTP status code
  "status": "Success",   // string - "Success" or "Error"
  "message": null,       // string|null
  "data": { ... }        // mixed - payload or null
}

Error Response

{
  "code": 422,                   // integer - HTTP status code
  "status": "Error",             // string - always "Error"
  "message": "Validation failed", // string - error description
  "data": null                   // null - always null on error
}

Error Codes

CodeMeaningWhen
401UnauthorizedMissing, invalid, or expired token
403ForbiddenToken lacks endpoint access or user lacks permission
404Not FoundResource does not exist
422Validation ErrorInvalid or missing request parameters
429Too Many RequestsRate limit exceeded

GET /api/v1/token/info Auth

Returns metadata about the current API token including expiration, abilities, and endpoint access. No parameters required.

Response — 200 OK

{
  "code": 200,                          // integer
  "status": "Success",                  // string
  "data": {
    "name": "Production Integration",   // string - token name
    "expires_at": "2026-11-21T00:00:00Z", // string|null - ISO 8601
    "last_used_at": "2026-05-20T14:30:00Z", // string|null - ISO 8601
    "allowed_endpoints": ["incidents", "labels"], // string[] - endpoint scopes
    "abilities": ["*"],                 // string[] - "*" or ["read:pii"]
    "has_pii_access": true,             // boolean - has read:pii ability
    "is_expired": false,                // boolean
    "is_disabled": false                // boolean
  }
}

Example Request

curl https://techrisk.paas.dana.id/api/v1/token/info \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -H "Accept: application/json"

GET /api/v1/ai/export Auth

AI-optimized bulk incident export with pagination via offset/limit. Returns flattened data suitable for AI/ML pipelines. Scope: ai-export

Query Parameters

ParameterTypeRequiredDefaultDescription
limitintegerNo100Max records to return (1–1000)
offsetintegerNo0Number of records to skip (≥ 0)
start_datedateNo-Filter from date (YYYY-MM-DD)
end_datedateNo-Filter to date, must be ≥ start_date (YYYY-MM-DD)
severitystringNo-One of: P1, P2, P3, P4, G, X1, X2, X3, X4, Non Incident
typestringNo-One of: Tech, Non-tech, Company Loss

Example Request

# First page — get 50 P1 incidents
curl "https://techrisk.paas.dana.id/api/v1/ai/export?limit=50&offset=0&severity=P1" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -H "Accept: application/json"
# Next page — increase offset by limit
curl "https://techrisk.paas.dana.id/api/v1/ai/export?limit=50&offset=50&severity=P1" \
  -H "Authorization: Bearer YOUR_TOKEN_HERE" \
  -H "Accept: application/json"

Pagination: Keep increasing offset by limit until has_more is false. The total field tells you the total matching records.

Response — 200 OK

{
  "code": 200,
  "status": "Success",
  "data": {
    "incidents": [
      {
        "id": 42,
        "no": "TR-2026-001",
        "title": "Payment Gateway Timeout",
        "summary": "...",
        "severity": "P1",
        "incident_type": "Tech",
        "pic": { "name": "John Doe" },
        "labels": ["Payment Gateway", "API"]
      }
    ],
    "pagination": {
      "limit": 50,
      "offset": 0,
      "total": 234,
      "has_more": true
    }
  }
}
